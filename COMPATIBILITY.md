# Harness compatibility

This matrix covers the 53 skills and 22 agents currently shipped by this repository. It is generated by `scripts/generate_harness_compatibility.ts`; edit the generator or source artifacts, then regenerate this file.

Claude Code, Codex, and Grok Build are native targets. OpenCode support targets stable V1 through `scripts/install_opencode.ts`; OpenCode V2 and `opencode2` are unsupported.

Reviewed against current harness documentation on 2026-08-24.

## Legend

- ✅ Native/full support
- 🟡 Adapter or compatibility-layer support with a caveat
- 🔌 External integration, credential, or tool required
- 🧪 Experimental harness API
- ❌ Unavailable
