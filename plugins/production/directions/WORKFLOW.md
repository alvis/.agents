# Production workflow

Read this before recording production assets, renders, feedback, or approval.

## Actions

Select by the requested action, not the subject noun.

| Action | Additional required instructions |
| --- | --- |
| Register footage, audio, graphics, fonts, LUTs, or templates; record a render/export; declare provenance, rights, or delivery | `production:track-assets`; read `essential:references/state.md`, Essential's shared domain README templates, and `production:templates/asset-manifest.md` |
| Review a cut or render; record feedback, approval, or approval validity after a change | `production:review-render`; read `essential:references/state.md`, `essential:references/approvals.md`, and `essential:references/reviews.md` |

Production skills write versioned manifests and review records. They never edit media bytes, invent provenance or rights facts, or carry approval across a revision without explicit preserved scope.

When establishing a production work stream, declare a `media-project` or
`asset-store` anchor per `essential:references/anchors.md`. Essential owns
state, decisions, journal, and handover through its state lifecycle contract.

## Standards

Production owns no standards. Follow the selected skill and the named Essential lifecycle contracts; do not import standards from an undeclared plugin.
