# Production workflow

Read this before recording production assets, renders, feedback, or approval.

## Actions

Read `production:references/ROUTING.md` to select the owning Production skill.

| Action | Additional required instructions |
| --- | --- |
| Register source assets or record a render/export | `production:track-assets`; read `essential:references/state.md`, Essential's shared domain README templates, and `production:templates/asset-manifest.md` |
| Record feedback, approval, or approval validity for a render | `production:review-render`; read `essential:references/state.md`, `essential:references/approvals.md`, and `essential:references/reviews.md` |

Production skills write versioned manifests and review records. They never edit media bytes, invent provenance or rights facts, or carry approval across a revision without explicit preserved scope.

## Standards

Production owns no standards. Follow the selected skill and the named Essential lifecycle contracts; do not import standards from an undeclared plugin.
