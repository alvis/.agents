# Video formats

The catalogue the `motion-design` action suggests formats from. Formats marked **avatar** need a live-action, avatar, or lip-sync generator beyond web animation and Blender; say so when suggesting one.

| Format | Typical purpose |
| --- | --- |
| Short reel / social short | Attention, entertainment, virality |
| Product demo | Show a product, feature, workflow |
| Explainer | Teach a concept or simplify something complex |
| Music video | Visual interpretation of music |
| Advertisement / commercial | Sell a product, brand, campaign |
| Brand film | Communicate identity, mood, values |
| Trailer / teaser | Build anticipation for a launch, film, game, product |
| Cinematic short / short film | Narrative storytelling |
| Sketch / comedy | Character-driven humour, memes, satire |
| UGC-style video (**avatar**) | Fake/virtual creator talking about a product or experience |
| Talking-head / presenter video (**avatar**) | Avatar or person delivering information |
| Podcast clip (**avatar**) | Visualised or avatar-generated conversational content |
| News / recap | Summarise events, trends, reports |
| Documentary / mini-doc | Factual storytelling with narration and generated visuals |
| Educational lesson | Courses, tutorials, training |
| How-to / tutorial | Step-by-step instruction |
| Walkthrough | Software, website, game, property, process |
| Case study / testimonial | Customer story or before/after narrative |
| Pitch video | Startup, investor, sales, proposal presentation |
| Presentation video | Slides turned into narrated motion content |
| Infographic / data story | Animate statistics, charts, timelines |
| Visual essay | Opinion or intellectual argument through narration + imagery |
| Storytime / narrated story | Fiction, history, Reddit-style stories, children's stories |
| Animation / cartoon | Character or stylised animation |
| Anime / episodic series | Recurring characters and longer-form fictional worlds |
| Game cinematic / machinima | Game-like worlds, lore, cutscenes |
| Concept film | Visualise something that doesn't exist yet: architecture, fashion, future products |
| Fashion film / lookbook | Clothing, styling, editorial presentation |
| Product beauty shot | Highly polished object shots, often 5–20 sec |
| Food / recipe video | Recipe demonstration or aesthetic food content |
| Travel film | Destination montage, itinerary, imaginary travel |
| Real-estate / architectural tour | Property or unbuilt-space visualisation |
| Event recap / highlight reel | Wedding, conference, launch, sports highlights |
| Personalised video | One video dynamically generated per customer/user |
| Interactive / branching video | Story or presentation changes based on viewer choices |
| Ambient / loop video | Background visuals, screensavers, Spotify Canvas-style loops |
| ASMR / satisfying video | Texture, transformations, surreal physical interactions |
| Meme / absurdist clip | Highly remixable, culturally driven micro-content |
| Virtual influencer content (**avatar**) | Persistent AI characters producing recurring content |
| Character dialogue / scene | Two or more synthetic characters acting together |
| Lip-sync / localisation (**avatar**) | Existing video translated and visually dubbed |
| Video greeting / message | Personalised birthday, invitation, announcement |
| Training simulation | Role-play for sales, support, safety, interviewing |
| Synthetic interview (**avatar**) | Interviewer + guest/avatar conversations |
| Previsualisation / storyboard film | Rough movie/ad concepts before real production |
