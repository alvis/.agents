# Recipe index

Every recipe the `motion-design` action can build a concept on, with the brief it fits and the file that holds its method. Recipe timings are starting allocations for the runtime each names. For personal and occasion pieces, the [story devices](references/story-devices.md) add shapes such as a toast round or a time machine.
