# Music and sensory formats

Read from `directions/motion-design/concept.md` when the chosen recipe is on this shelf.

## How sensory pieces hold attention

- The hook can be a sound–image relationship the viewer wants to stay inside, not a question awaiting an answer. Name that relationship before designing shots.
- Reward viewing now rather than promising a later event; never add artificial cliffhangers or jump scares to manufacture retention.
- A shorter excerpt ends on a finished musical phrase or sensory action, never mid-gesture.
- These entries own the visual form and its relation to the track; for songwriting, lyric timing, and scoring see [music](directions/motion-design/music.md). Use only music, lyrics, voices, and visuals with recorded rights ([track](directions/track.md)).
- Timings are starting allocations measured in the track's sections.

## MUS1 · Narrative music video
- Use when: a track with meaningful section changes carries one emotional story.
- Ingredients: one emotional premise; a few recurring images or one recurring object; visual development that adds what the lyrics do not say.
- Method: an evocative world with one meaningful absence or anomaly, introduced on the first phrase → develop the relationship in the verse → broaden or transform it at the chorus → reinterpret at the contrasting section → the returning phrase carries new meaning → complete the emotional movement. Stage: cut on musical or narrative turns, not every beat; leave visual room under an important line.
- Timing: one story beat per section; no hook placed before the song starts.
- Variations: a serialized musical drama, with DOC8's recurring world ([mystery](directions/motion-design/recipes/mystery-fiction.md)).
- Fix: if every lyric is illustrated literally or a twist is forced onto an atmospheric track, develop one motif instead.
- Finish test: does the song feel different after the images have developed it?

## MUS2 · Virtual performer / animated band
- Use when: a character or group should be remembered as a performer with its own world.
- Ingredients: a distinctive performer; a readable performance space; relationships between members or personas; a repeatable stage identity.
- Method: one unmistakable gesture, silhouette, or attitude within the opening phrase → the performance rule → staging varied by section → contrast personalities or spaces → the signature image returns with more weight → resolve. Stage: a performer, not a mascot over a waveform; close-ups for accents, wide shots for ensemble.
- Timing: identity fixed within the first phrase; location changes only at section boundaries.
- Variations: an animated concert or dance battle, adding COM8's competitive stakes ([comedy](directions/motion-design/recipes/comedy.md)).
- Fix: if identity drifts between shots or lip movement distracts, lock the character sheet and animate mouths only as far as the style needs.
- Finish test: would a viewer want another song from this performer?

## MUS3 · Lyric film / kinetic typography
- Use when: reading the words should add emotional clarity to a vocal track.
- Ingredients: readable phrase groupings; a type treatment with an expressive purpose; a few meaningful transformations.
- Method: the first important phrase set inside a distinctive visual world → establish a reading rhythm → vary emphasis by meaning → contrast sections or voices → repeat key words in changed context → resolve with the musical ending. Stage: one stable reading area; animate emphasis, not every syllable; never dense text over the busiest image.
- Timing: reveal each phrase at or slightly before its sung onset, taken from the word timestamps, so the reader is never behind the singer.
- Variations: kinetic spoken poetry, with [X3](directions/motion-design/recipes/essay.md)'s associative structure.
- Fix: if captions race the singer, group phrases and cut motion; accessibility captions may need a separate plain treatment.
- Finish test: can the viewer read the words and feel the mood without decoding the motion?

## MUS4 · Educational song / public-service message
- Use when: one message should be remembered through a refrain.
- Ingredients: one clear message; an original catchy refrain; several related examples; a final application.
- Method: catchy phrase paired with a legible visual contradiction → the pattern clear after one example → varied examples → refrain returns → context shifts to reveal the real message → specific, accurate takeaway as the song completes. Stage: one mini-stage per example; consistent character and musical cues, renewed by variation, not chaos.
- Timing: one example per verse line pair; the takeaway lands on the final refrain.
- Variations: sung history, with HIS3's structure ([history](directions/motion-design/recipes/history-true.md)).
- Fix: if humour obscures or misdemonstrates the safe behaviour, check every example against the message.
- Finish test: can someone state the message without replaying the song?

## MUS5 · Musical machine / abstract visual performance
- Use when: the attraction is watching visual behaviour produce the music.
- Ingredients: a clear mapping from musical events to visual behaviour; a system that can develop across sections.
- Method: one action visibly producing one sound → add a complementary layer → combine parts → new register or behaviour at a section change → the whole system together → finish or return to the first motif. Stage: drive each mapped event from the timing data object in [build](directions/motion-design/build.md); start trajectories before impact so contact lands on the sound; keep a hierarchy when parts overlap.
- Timing: one new mapping per section, so each is learned before the next arrives.
- Variations: a product spectacle with the product as instrument, kept to an honest commercial promise.
- Fix: if particles react identically to everything, give each part its own developing behaviour.
- Finish test: can the viewer say which visual made which sound?

## MUS6 · Impossible process / tactile transformation
- Use when: a familiar process done with the wrong materials satisfies through surprise and completion.
- Ingredients: a familiar process; a substitution rule; precise cause and effect; a finished result.
- Method: a recognisable action on an object of the wrong material, shown cleanly → a related substitution → combine results → complete the process → the finished object in use, or a return to the opening rule. Stage: hands, surfaces, and tools legible; match action sounds to the sensation, since one precise crunch can carry the reward; music optional.
- Timing: one substitution per step; hold each contact long enough to register its sound.
- Variations: a recipe or assembly where each ingredient is a trait or feature.
- Fix: if steps become unrelated morphs or feel weightless, keep contact, weight, and timing tactile rather than imitating stop-motion texture.
- Finish test: are both the completion and the material surprise satisfying?

## MUS7 · Ambient world / study or sleep companion
- Use when: the piece accompanies another activity rather than demanding attention.
- Ingredients: a coherent place; a soundscape fit for the purpose; subtle recurring movements; a stable visual hierarchy.
- Method: offer the desired state at once (warm desk, quiet train, rainy window), promising "stay here", not a reveal → sustain small cycles → admit only changes that keep the function → keep continuity across track changes → close gently or loop cleanly. Stage: movement away from the resting area; foreground, environment, and distant life on different cycle lengths, each dividing the loop length, so the loop seam is hard to spot; no abrupt level changes, sudden effects, or flashes.
- Timing: the loop length sets every cycle length.
- Variations: a short loop for a music-player canvas.
- Fix: if copy claims therapeutic benefit without evidence, describe the mood instead.
- Finish test: does it work while the viewer is doing something else?

## MUS8 · Animation meme / dance loop / character earworm
- Use when: an original character and short phrase should invite rewatching and reinterpretation.
- Ingredients: an original character; a short musical phrase; a movement rule; one clear variation or return.
- Method: signature pose and sound together at once → vary pose, scale, or partner → a tiny reward for the variation → complete the phrase → return to the start when looping serves the piece. Stage: simple silhouette readable on a phone; keep the signature stable while changing one element.
- Timing: one musical phrase per loop, so the phrase's own return motivates the loop point.
- Variations: a partner or crowd joining on the repeat.
- Fix: if the loop hides a promised outcome or uses unlicensed audio, loop only a complete phrase you own.
- Finish test: is the character's attitude readable from one small action?
