# Science and discovery recipes: simulation, scale, and play

Read from `directions/motion-design/concept.md` when the chosen recipe is on this shelf.

Simulation, scale, riddle, and game-video forms (DIS5–DIS8). Apply the shelf rules and finish test in [science: mechanisms](directions/motion-design/recipes/science-mechanisms.md).

## DIS5 · Simulation of emergent behaviour

- Use when: a comprehensible model generates a pattern from simple rules.
- Ingredients: the rules, an initial condition, one changed parameter, several runs when randomness matters.
- Method: two near-identical populations side by side, the differing rule revealed before running → baseline run → ask for a prediction → run the intervention → inspect the surprise → change or repeat a condition → separate the model's lesson from claims about reality. Teach only the rules the result needs; pair local agents with a simple aggregate display; a discrete sound marks each round.
- Timing: setup 0–10 s, baseline 10–20 s, prediction pause 20–24 s, intervention 24–45 s, repeat 45–54 s, lesson 54–60 s.
- Variations: repeat with a new seed instead of a new rule to show the pattern is robust.
- Fix: only the most dramatic seed is shown or assumptions are hidden; show several seeds and state assumptions. A simulation illustrates a possibility; it does not validate the real mechanism.
- Finish test: Did the viewer see the mechanism produce the pattern?

## DIS6 · Scale journey or deep-time compression

- Use when: a size, distance, quantity, or interval is too large to grasp without a familiar anchor; this is the audience-facing form of E6.
- Ingredients: the anchor, a stated scale rule, a few meaningful thresholds.
- Method: the anchor inside the larger field with the scale rule shown at once → teach the ruler or clock → pass a few thresholds → tie each back to the question → the revealing comparison → back to the anchor. Disclose every rate change; vary detail instead of accelerating continuously; a held frame conveys duration better than a montage.
- Timing: anchor and rule 0–8 s, thresholds 8–48 s, comparison 48–55 s, return 55–60 s.
- Variations: E6 owns the rules for switching axes; long-form versions can run an hour.
- Fix: logarithmic and linear scales mixed invisibly; mark the scale type whenever it changes.
- Finish test: Did the viewer grasp a relationship, not just largeness?

## DIS7 · Riddle or predict-the-outcome challenge

- Use when: a fair problem rewards understanding why the answer works.
- Ingredients: stakes, every necessary rule, objects whose differences matter, the tempting mistake, the solution.
- Method: goal and constraint together → rules taught visually → a pause or prediction invitation → the tempting mistake → the reasoning → a small variation. Keep the full state visible and add nothing during the pause; use a calm cue or explicit pause instruction, not a countdown that blocks reading.
- Timing: rules 0–20 s, thinking pause 20–24 s plus a pause-now line for viewers who need longer, mistake 24–32 s, reasoning 32–52 s, variation 52–60 s.
- Variations: a story setting is optional; the puzzle alone carries forward motion.
- Fix: the solution depends on a hidden rule or arbitrary exception; state every rule before the pause.
- Finish test: Could an attentive viewer have solved it from what was shown?

## DIS8 · Interactive game-video

- Use when: the viewer can affect the experience through a legible action on a platform that supports it.
- Ingredients: one obvious input, visible feedback, short branches with complete outcomes, a non-interactive route when needed.
- Method: one safe demonstration with the instruction beside the choice → teach one input → immediate feedback → a meaningful choice → its consequence → a harder decision → a finished branch, replay optional. Reserve stable screen zones for choices clear of captions, player controls, and mobile cropping.
- Timing: demonstration 0–8 s, then branches short enough that each reaches an ending within the platform's interaction limits.
- Variations: the Choose-your-path device in [story devices](references/story-devices.md) shows both paths in one linear film.
- Fix: a HyperFrames render is linear, so promised branching the player cannot deliver breaks the piece; confirm the interaction on the target device and never hide the path to an ending.
- Finish test: Does the viewer's choice change what they experience?
