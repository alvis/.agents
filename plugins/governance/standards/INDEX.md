# Governance standards index

Select applicable standards for authored artifacts from the table below. The
protocol that governs selection, scanning, and rule lookup is
`essential:directions/standards.md`; this file only says which standard applies.

| Applies to | Standard |
| --- | --- |
| Any authored agent, skill, or standard | `governance:standards/authoring/` |
| An authored artifact that dispatches subagents | `governance:standards/delegation/` |

Governance owns authoring invariants and templates, not standards governing its
own work: a standard being authored is the target artifact, not an implicit
standard governing unrelated governance work. Do not select a standard from an
undeclared plugin.
