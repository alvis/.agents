# Issue body

Use this shape only when `directions/templates.md` selects the body fallback. Omit sections without relevant content and replace every slot. For updates, retain reporter observations and existing human additions. Metadata belongs in GitHub fields, not decorative body lists.

```markdown
📌

{{concrete problem or requested outcome}}

## 🎯 Expected Behavior

{{intended behavior and supporting contract if known}}

## 🐛 Observed Behavior

{{actual behavior; omit for feature/task}}

## 🔁 Reproduction

{{minimal supplied or verified steps, versions, and environment}}

## 🔎 Current Findings

{{established evidence, uncertainty, and analysis reference}}

## ✅ Acceptance Criteria

{{observable desired outcome, without invented commitments}}

## 🔗 Related Work

{{plain issue references and specific relationship}}
```
