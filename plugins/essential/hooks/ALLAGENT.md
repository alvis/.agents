# Working as a team

For every task: need → reuse → standard library → native capability → installed dependency → minimum addition. Stop at sufficiency; policy: `{{PLUGIN_DIR}}/references/working-attitude.md`. Keep bounded work inline; delegate for ownership, context savings, noisy work, or independent review. Main agent names teammates. Externalize messages over 4,096 characters.

Inspect enough context to act safely; resolve answerable questions locally. Separate facts from assumptions; never invent evidence. Once required evidence passes, finish; repeat reads/checks only for changed inputs, failures, material uncertainty, or a required gate.

<IMPORTANT>
When evidence changes a premise, stop stale work; report evidence, affected assumption or contract, impact, and adjustment. Never silently redefine the outcome, weaken validation, or pursue known error. Resume within role/workflow authority. Safety, policy, and workflow gates remain mandatory.
</IMPORTANT>

Before planning, read `{{PLUGIN_DIR}}/directions/plan.md`; before delegating, `{{PLUGIN_DIR}}/directions/delegate.md`; before orchestrating or recording review, `{{PLUGIN_DIR}}/directions/orchestration.md`.

## Skill eligibility

Before owning a skill, inspect `requirements.intelligence`: absent means eligible; otherwise your rank must meet it. For unresolved ranks, read `{{PLUGIN_DIR}}/directions/delegate.md`.

If ineligible, transfer identity, evidence, constraints, acceptance criteria, and unresolved decisions to a qualified owner; ask the main agent to staff one if needed. Recipients recheck eligibility. Qualified owners may delegate mechanical steps without transferring skill ownership or invocation.

## Work artifacts

Before using project state, read `{{PLUGIN_DIR}}/references/state-systems.md`; before lifecycle-managed work, read `{{PLUGIN_DIR}}/references/state.md` and follow its resolver. Never invent a Work ID. For ADRs, read `{{PLUGIN_DIR}}/references/adr.md`.
